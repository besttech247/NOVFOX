# سكانر السكالبنغ (Scalping Scanner)

لوحة ويب عربية لإشارات الشراء اللحظية على فريمات 1m و 5m — Binance / Bybit / KuCoin، سبوت وفيوتشر، مع سيرفر يعمل 24/7.

## المزايا

- **محرك إشارات شراء فقط** بنظام نقاط 0–100 (EMA، VWAP، RSI، انفجار الحجم، الاتجاه العام، الاختراقات، Funding Rate و Open Interest للفيوتشر)
- **سيرفر 24/7**: السكانر يعمل على السيرفر حتى مع إغلاق المتصفح، والواجهة تستقبل البث اللحظي (SSE)
- **تسجيل دخول** بحساب واحد (كلمة مرور) مع حماية من تخمين الباسورد
- **زر إيقاف/تشغيل كامل** + **التحكم بفترات جلب البيانات** + **حماية IP من الحظر** (تحديد معدل الطلبات + تراجع تلقائي عند 429/418)
- **أرشيف الإشارات** في PostgreSQL (يُحتفظ بآخر 3 أيام)
- **باك تست** على البيانات التاريخية + **سجل صفقات**
- واجهة متجاوبة للجوال (RTL)

## التشغيل المحلي

```bash
npm install

# نافذة 1 — السيرفر
npm run dev:server

# نافذة 2 — الواجهة
npm run dev
```

ثم افتح http://localhost:3000 — كلمة المرور الافتراضية محلياً: `admin` (غيّرها عبر `ADMIN_PASSWORD`).

للتجربة بدون اتصال بالمنصات: `DEMO_MODE=1 npm run dev:server`

## النشر على Railway

1. اربط هذا المستودع: **New Project → Deploy from GitHub repo**
2. أضف قاعدة بيانات: **+ New → Database → PostgreSQL** (يُربط `DATABASE_URL` تلقائياً)
3. أضف المتغيرات:
   - `ADMIN_PASSWORD` — كلمة مرور لوحة التحكم (إلزامي)
   - `SESSION_SECRET` — اختياري؛ سرّ توقيع الجلسات
4. Railway يبني عبر `Dockerfile` تلقائياً

## المتغيرات البيئية

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | منفذ السيرفر (Railway يضبطه تلقائياً) | `3001` |
| `DATABASE_URL` | اتصال PostgreSQL — بدونه يعمل السيرفر بدون حفظ | — |
| `ADMIN_PASSWORD` | كلمة مرور الدخول | `admin` (تطوير فقط) |
| `SESSION_SECRET` | سر توقيع كوكي الجلسة | مشتق من كلمة المرور |
| `DEMO_MODE` | `1` = بيانات تجريبية بدون منصات | — |
| `PGSSL` | `false` لتعطيل SSL لقاعدة البيانات | — |

## البنية

```
api/          السيرفر (Hono): المحرك، المصادقة، قاعدة البيانات، REST + SSE
src/          الواجهة (React + Tailwind): الجداول، التنبيهات، الباك تست، السجل
Dockerfile    بناء متعدد المراحل للنشر
```

> هذه الأداة للمسح الفني فقط وليست نصيحة استثمارية. السكالبنغ عالي المخاطر.
